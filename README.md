## 프로젝트 소개

**몽대장의 어린이 재난안전교실**은 유아 및 초등학교 저학년 아동을 위한 모바일 재난안전교육 콘텐츠입니다.

학습자는 또래 학습 도우미인 **몽대장**과 함께 지진과 화재를 배우고, 재난 상황에서 필요한 행동을 직접 선택합니다. 터치·드래그 인터랙션, 상황별 피드백, 대피 미니게임을 통해 학습 내용을 경험하고, O/X 퀴즈로 핵심 개념을 복습합니다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 유아 및 초등학교 저학년 아동 |
| 학습 범위 | 지진·화재 |
| 학습 구조 | 개념학습 → 대비학습 → 실전학습 |
| 개발 환경 | Unity 2022.3.60f1, C# |
| 연구 성과 | 스마트미디어저널 15권 2호 게재, 2026 |

## 개발 배경

어린이는 재난 상황을 판단하고 대응하는 경험이 부족해, 발달 수준에 맞는 반복적인 안전교육이 필요합니다. 기존 교육에서 학습자의 흥미를 유지하고 배운 내용을 실제 행동으로 연결하는 데 어려움이 있다는 점에 주목했습니다.

본 프로젝트는 **게임 기반 학습(Game-Based Learning, GBL)**을 적용해 어린이가 스스로 참여할 수 있는 학습 환경을 만들고자 했습니다. 아동중심디자인 원칙과 Bloom의 학습 영역 이론을 바탕으로, 개념을 이해한 뒤 대비 방법을 배우고 실전 상황에 적용하도록 학습 단계를 구성했습니다.

교육적 요구는 보호자 **61명**을 대상으로 한 사전 조사를 통해 확인했습니다.

## 3단계 학습 설계

지진과 화재는 각각 **개념·대비·실전**의 3단계로 구성됩니다. 이전 단계에서 배운 내용을 다음 단계에서 활용하도록 설계했습니다.

| 단계 | 학습 내용 | 상호작용 |
| --- | --- | --- |
| **1단계 · 개념학습** | 지진의 진도별 현상, 화재 3요소 등 재난의 기본 개념과 현상 | 터치·드래그를 활용한 개념 탐색 |
| **2단계 · 대비학습** | 재난에 대비하는 방법과 상황별 안전 행동 | 그림 선택지와 선택 결과에 대한 피드백 |
| **3단계 · 실전학습** | 학교에서 지진·화재가 발생했을 때의 대응과 대피 | 1인칭 시점 시뮬레이션, 행동 선택, 대피 미니게임 |

학습 내용은 소방청·행정안전부·교육부 등 공공기관에서 발행한 아동 재난안전교육 자료를 참고해 구성했습니다.

## 주요 기능

### 재난 상황별 체험 학습

- 지진·화재의 개념과 대응 방법을 단계적으로 학습
- 터치·드래그를 통해 학습 요소와 직접 상호작용
- 상황별 행동 선택지로 올바른 대처 방법을 판단
- 선택 결과에 대한 피드백으로 행동의 이유를 이해
- 대피 미니게임에서 학습한 내용을 적용

### 몽대장의 학습 안내

몽대장이 상황을 설명하고 학습자의 선택에 피드백을 제공합니다. 자막과 AI 더빙 음성을 함께 활용해 학습 흐름을 안내하며, 자막 표시 여부는 설정에서 조절할 수 있습니다.

### O/X 복습 퀴즈

각 스테이지의 핵심 개념을 O/X 문제로 복습합니다.

| 구분 | 문항 수 | 점수 |
| --- | --- | --- |
| 1단계 | 5문항 | 정답당 10점 |
| 2단계 | 5문항 | 정답당 10점 |
| 3단계 | 10문항 | 정답당 10점 |

### 배지와 랭킹

- 학습 스테이지를 완료하면 배지와 점수 획득
- ‘나의 배지’ 화면에서 학습 성취 확인
- 퀴즈 점수와 배지 점수를 합산해 랭킹 산정
- 같은 교육기관에 속한 사용자 간 순위 제공

### 사용자 설정

- BGM 크기 조절
- 자막 표시 켜기·끄기
- 사용자 정보 수정 및 탈퇴

콘텐츠의 교육적 타당성과 시스템 적합성을 검토하기 위해 **다학제적 전문가 12명**을 대상으로 평가를 진행했습니다.

| 항목 | 내용 |

| 평가 참여자 | 아동학 전공 교수·대학원생, 안전교육 담당자, 초등·유치원 교사 등 |

| 전체 내용 타당도 지수 | **S-CVI/AVE = 0.85** |

이 평가는 전문가 판단을 바탕으로 **콘텐츠 설계의 타당성과 교육적 적합성**을 검토한 결과입니다. 실제 아동의 재난 대응 능력이나 학습 성취도 향상에 대한 실증적 효과 검증은 후속 연구 과제입니다.

## 프로젝트 구조

저장소 루트 안의 `mong-disaster-safety-class/`가 Unity 프로젝트 폴더입니다.

```text
.
├── .gitattributes
├── .gitignore
└── mong-disaster-safety-class/
    ├── Assets/
    │   ├── Animation/          # 애니메이션
    │   ├── Audio/              # 음성·효과음·BGM
    │   ├── Fonts/              # 폰트
    │   ├── Images/             # 이미지
    │   ├── Prefabs/            # 재사용 게임 오브젝트
    │   ├── Scenes/             # 학습 시나리오와 화면
    │   └── Scripts/
    │       ├── Common/         # 공통 기능
    │       ├── Eq_Scripts/     # 지진 관련 학습
    │       ├── Eq_Step4_Scripts/
    │       ├── Fire_Scripts/   # 화재 관련 학습
    │       ├── Fire_Step4_Scripts/
    │       ├── Managers/       # 관리 로직
    │       ├── MyBadge/        # 배지
    │       ├── Quiz/           # 퀴즈
    │       ├── Ranking/        # 랭킹
    │       ├── Setting/        # 설정
    │       ├── Sign_Up/        # 사용자 등록
    │       └── Start/          # 시작 화면 관련 기능
    ├── Packages/
    └── ProjectSettings/
```

## 실행 방법

### 준비 사항

- Unity Hub
- Unity Editor **2022.3.60f1**

### 프로젝트 열기

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/yunakim17/mong-disaster-safety-class.git
   ```

2. Unity Hub에서 **Add → Add project from disk**를 선택합니다.
3. 내려받은 저장소 내부의 `mong-disaster-safety-class/` 폴더를 선택합니다. `Assets`, `Packages`, `ProjectSettings`가 있는 폴더입니다.
4. Unity `2022.3.60f1`로 프로젝트를 엽니다.
5. 패키지와 에셋 가져오기가 완료되면 학습 Scene을 열고 **Play**를 눌러 실행합니다.
